# GWM Stats на PS3 — установка

Плагин считает, во что и сколько ты играешь на PS3, и показывает это
на [gowithme.club](https://gowithme.club). Работает с любой игрой: с диска,
с жёсткого диска, с PSN. Трофеи подхватывает тоже.

Нужна прошитая консоль — CFW или HFW с PS3HEN — и установленный webMAN.
Больше ничего: ни компьютера рядом во время игры, ни аккаунта PSN.

Установка — минут на пять.

## 1. Получить токен

Токен — это твой ключ к серверу, пока мы выдаём их вручную.
Напиши нам <!-- СЮДА: телеграм или почта --> и скажи, как назвать консоль
и под каким ником показывать тебя в статистике. В ответ придёт токен.

Без токена плагин не отправляет наружу ничего — вообще ни одного запроса.

## 2. Скачать плагин

Файл `gwm.sprx` — со страницы релизов:
<https://github.com/gowithme-club/ps3-playtime-tracker/releases>

## 3. Положить два файла на консоль

Узнай IP консоли: XMB → «Настройки» → «Настройки сети» → «Список настроек».
Дальше зайди на неё по FTP — с компьютера (FileZilla, Finder, проводник)
или прямо с консоли через multiMAN.

В папку `/dev_hdd0/plugins/` положи:

- скачанный `gwm.sprx`;
- файл `gwm.cfg` — обычный текстовый, из одной строки:

```ini
token = сюда_твой_токен
```

Адрес сервера вписывать не надо, он уже зашит.

## 4. Первый запуск — без автозагрузки

Проверять надо на живой системе, а не после перезагрузки. Открой в браузере,
подставив IP консоли:

```
http://<ip>/loadprx.ps3?prx=/dev_hdd0/plugins/gwm.sprx
```

Секунд через десять XMB покажет уведомление о загрузке. Консоль при этом
должна быть уже загружена — дождись XMB и подожди ещё пару минут, иначе
загрузка плагина может уронить систему. Если что-то пойдёт не так, выключи
консоль кнопкой питания — на диске ничего не изменилось.

## 5. Проверить, что работает

Открой в браузере:

```
http://<ip>/dev_hdd0/tmp/gwm/status.txt
```

Должно быть `token = set` и `heartbeat = ... 200`. Значит консоль
достучалась до сервера. Запусти любую игру — через десяток секунд
в той же строчке `game` появится её название.

А когда выйдешь из игры, XMB сам покажет, сколько ты играл и уехала ли
сессия на сервер.

## 6. Автозагрузка — сама

Делать ничего не нужно. Как только сервер впервые ответил, плагин прописывает
себя в `/dev_hdd0/autoexec.bat` и говорит об этом в углу экрана:

```
gwm-stats
Autostart enabled
```

Дальше он поднимается при каждой загрузке консоли. Чужие плагины в этом файле
остаются на месте. Если автозагрузка не нужна, добавь в `gwm.cfg` строку
`autostart = false`.

## Если XMB не поднимается

Выключи консоль кнопкой питания и включи **не активируя HEN** — плагины
при этом не подключаются. Дальше зайди по FTP, убери строку с `gwm.sprx`
из `autoexec.bat` и допиши в `gwm.cfg` строку `autostart = false` — иначе
плагин впишет её обратно при следующей ручной загрузке.

## Что уходит на сервер

Название и id игры, её версия, откуда запущена, сколько длилась сессия,
версия прошивки, трофеи. Консоль опознаётся хешем — сам идентификатор
консоли наружу не уходит. Личных данных, друзей, сообщений плагин
не читает и не отправляет.

Если что-то не заработало — [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
Подробности для тех, кому интересно устройство: [DEVELOPMENT.ru.md](DEVELOPMENT.ru.md)
и [INSTALL.md](INSTALL.md).
