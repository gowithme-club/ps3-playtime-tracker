# Установка

Подробная версия. Если нужно просто поставить и играть, есть короткая —
[QUICKSTART.md](QUICKSTART.md), минут на пять.

## Что нужно

- PS3 с CFW или с HFW и PS3HEN;
- установленный webMAN;
- токен — пока выдаётся вручную.

Компьютер нужен только на время установки. Во время игры он не нужен,
аккаунт PSN — тоже.

## 1. Положить два файла на консоль

Узнать IP консоли: XMB → «Настройки» → «Настройки сети» → «Список настроек».
Дальше зайти на неё по FTP — с компьютера (FileZilla, Finder, проводник)
или прямо с консоли через multiMAN.

В папку `/dev_hdd0/plugins/` положить:

- `gwm.sprx` — со страницы
  [релизов](https://github.com/gowithme-club/ps3-playtime-tracker/releases);
- `gwm.cfg` — обычный текстовый файл:

```ini
token = сюда_твой_токен
```

Больше в нём ничего не нужно: адрес сервера зашит в плагин. Без токена плагин
не отправляет наружу ни одного запроса.

Если уведомления в углу экрана будут мешать, их можно выключить — добавь
второй строкой `popups = false`, и плагин продолжит работать молча.
А строкой `autostart = false` — запретить ему прописываться в автозагрузку
(см. шаг 4).

## 2. Первый запуск — вручную, не через автозагрузку

Плагин работает внутри `vsh.self`. Если он упадёт, зависнет весь XMB, а вместе
с ним webMAN и FTP — и зайти на консоль, чтобы что-то исправить, будет уже
нельзя. Поэтому сначала пробуем на живой системе: ничего постоянного при этом
не меняется, а откат — выключение кнопкой питания.

**Консоль должна быть уже загружена.** Дождись, пока появится XMB, и подожди
ещё пару минут. Загрузка плагина в тот момент, когда XMB ещё поднимается,
однажды уронила консоль целиком — до полного молчания.

Открыть в браузере, подставив IP консоли:

```
http://<ip>/loadprx.ps3?prx=/dev_hdd0/plugins/gwm.sprx
```

Секунд через десять в правом верхнем углу XMB появится уведомление:

```
gwm-stats <версия> loaded: ТвойПрофиль
```

Если вместо имени профиля написано `offline (no token)` — плагин запустился,
но не нашёл токен: проверь `gwm.cfg`.

## 3. Проверить, что всё работает

Открыть в браузере:

```
http://<ip>/dev_hdd0/tmp/gwm/status.txt
```

Должно быть `token = set` и `heartbeat = ... 200` — значит консоль достучалась
до сервера. Запусти любую игру: через десяток секунд в строке `game` появится
её название.

Выйди из игры — секунд через десять-двадцать XMB покажет, что получилось:

```
gwm-stats: Demon's Souls
Session 47 min, sent
```

`sent` значит, что сессия принята сервером. Если написано `queued` — она
сохранена на консоли и уедет позже, когда появится связь; ничего не потеряется.

## 4. Автозагрузка включается сама

Делать ничего не нужно. Как только сервер впервые ответил `200` — то есть
плагин поднялся, токен верный и сеть есть, — плагин дописывает себя
в `/dev_hdd0/autoexec.bat` и показывает уведомление:

```
gwm-stats
Autostart enabled
```

С этого момента он поднимается при каждой загрузке консоли. Проверить можно
глазами:

```
http://<ip>/dev_hdd0/autoexec.bat
```

Раньше первого ответа сервера плагин себя не прописывает — специально: иначе
при каждой загрузке консоли поднимался бы модуль, о котором ещё ничего
не известно.

Чужие строки в файле остаются на месте, своя дописывается к ним в конец.
Второй раз плагин не дописывается, сколько бы раз ни перезапускался. Если
файла не было — создаст.

Не нужна автозагрузка (или свой порядок загрузки плагинов) — добавь
в `gwm.cfg` строку `autostart = false`, и файл останется нетронутым.

Именно `autoexec.bat`, а не `boot_plugins.txt`. Первый грузит плагин после
того, как XMB уже поднялся, и неудачная загрузка не оставит без консоли.
Второй грузит его во время загрузки системы, до появления XMB: споткнётся
плагин — XMB не поднимется вообще. Переезжать туда стоит, только когда
несколько перезагрузок подряд прошли чисто.

## Если что-то пошло не так

Разбор частых случаев — XMB не поднимается, нет уведомления, данные не уходят,
что значат коды в сообщениях — в [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
